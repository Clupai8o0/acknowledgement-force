Section E

Reading the record

The same data on two machines with two different jobs. D14 draws the line in one place and it is structural rather than a policy: the web API has no endpoint that can write a day's verdict. There is nothing to disable, because there is nothing to call. If you could settle a day in a browser tab you would settle it half-watching something else — reflex-ticking with extra steps, which is v1's death reproduced faithfully in a new medium.
